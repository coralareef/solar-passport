MODEL TRANSPARENCY

What this MVP does

Buildings. Calculates a pre-solar and post-solar bill, values self-consumption separately from export, models CAPEX/O&M/degradation/inverter replacement, and compares multiple system sizes.

Projects. Calculates P50/P90 energy, CFADS, debt service, DSCR, project/equity IRR, NPV and LCOE. It solves the tariff needed to meet the target equity IRR, P90 DSCR and zero project NPV.

Solar resource. If NREL_API_KEY is configured on the server, the Building Passport uses PVWatts v8. Otherwise it uses the visible specific-yield assumption entered by the user.

Current limitation. This MVP uses simplified monthly building load matching and annual project cash-flow modelling. It should be upgraded with interval load data, detailed tariff/net-metering rules, taxes/depreciation, construction drawdowns, DSRA, LLCR and verified grid/curtailment data before lender reliance.
